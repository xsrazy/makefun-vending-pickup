A single pickup line spoken by a vending machine to a passing human, entered in make.fun's "One Line, One Minute: The Vending Machine Pickup Line Contest" bounty.

## Run it

```sh
python3 main.py
```

The program writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline.
